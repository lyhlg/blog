마크다운 파일을 열고 `Cmd+Shift+V`를 누릅니다.
하얀 배경에 단색 텍스트가 쭉 나열됩니다.

개발자라면 익숙할 수 있습니다.
하지만 요즘은 PO, PD, 기획자도 `.md` 파일을 봅니다.
모노레포의 README, ADR, RFC 문서를 함께 읽어야 하니까요.

**익숙하지 않은 분들에게 기본 마크다운 미리보기는 읽기 어렵습니다.**

그래서 직접 만들었습니다. **Markdown Prettier**.

## TLDR

> - VS Code 기본 마크다운 미리보기는 가독성, 네비게이션, 발표 기능이 부족합니다
> - Markdown Prettier는 색상 헤딩, TOC 사이드바, 프레젠테이션 모드 등을 지원합니다
> - 기존 확장 프로그램(MPE, Markdown All in One)과의 차별점을 비교합니다

## 기존 마크다운 뷰어의 불편함들

VS Code의 기본 마크다운 미리보기를 써보면 몇 가지 불편함이 있습니다.

**1. 헤딩 구분이 안 됩니다**

H1과 H3의 차이가 글씨 크기뿐입니다.
문서가 길어지면 어떤 레벨의 제목인지 한눈에 파악하기 어렵습니다.

**2. 목차(TOC)가 없습니다**

긴 문서에서 원하는 섹션으로 이동하려면 스크롤을 해야 합니다.
어디에 뭐가 있는지 전체 구조를 파악하기 힘듭니다.

**3. 프레젠테이션이 안 됩니다**

마크다운으로 작성한 문서를 팀에 공유할 때, 미리보기 화면을 그대로 보여주기엔 밋밋합니다.
별도의 슬라이드 도구로 옮겨야 하는 번거로움이 있습니다.

**4. Mermaid 다이어그램을 지원하지 않습니다**

기본 미리보기에서는 Mermaid 코드가 그냥 텍스트로 출력됩니다.
별도 확장을 설치해야 합니다.

**5. 폰트 크기를 조절할 수 없습니다**

발표나 화면 공유 시 글씨가 작다고 느껴도 조절 방법이 없습니다.
VS Code 전체 줌을 해야 합니다.

그렇다면 기존 확장 프로그램으로는 해결이 될까요?

## 기능 비교: 기존 뷰어 vs Markdown Prettier

| 기능 | VS Code 기본 | Markdown Preview Enhanced | Markdown All in One | **Markdown Prettier** |
|------|:---:|:---:|:---:|:---:|
| **헤딩 색상 구분** | ❌ 단색 | ❌ 단색 | ❌ 단색 | ✅ 레벨별 5색 |
| **TOC 사이드바** | ❌ 없음 | ❌ 본문 내 삽입 | ❌ 본문 내 삽입 | ✅ 좌측 사이드바 + 활성 섹션 하이라이트 |
| **프레젠테이션 모드** | ❌ | ✅ reveal.js 기반 | ❌ | ✅ 내장 (`---` 구분자) |
| **코드 하이라이팅** | 기본 | ✅ highlight.js | ❌ | ✅ Atom One Dark 테마 |
| **Mermaid 다이어그램** | ❌ 확장 필요 | ✅ 내장 | ❌ | ✅ 내장 + 테마 자동 전환 |
| **스크롤 동기화** | 불안정 | ✅ 안정적 | ❌ | ✅ 헤딩 기반 |
| **폰트 크기 조절** | ❌ | ❌ | ❌ | ✅ A+/A- (10~20px) |
| **라이브 편집** | ❌ | ❌ | ❌ | ✅ 더블 클릭으로 즉시 편집 |
| **Frontmatter 처리** | 그대로 노출 | ✅ 파싱/숨김 | ❌ | ✅ 자동 숨김 |
| **Light/Dark 모드** | VS Code 종속 | 커스텀 | VS Code 종속 | ✅ 자동 전환 |
| **PDF 내보내기** | ❌ | ✅ Pandoc 기반 | ❌ | ✅ 내장 |

Markdown Preview Enhanced(MPE)가 가장 많은 기능을 가지고 있지만,
**헤딩 색상 구분, TOC 사이드바, 폰트 크기 조절**은 Markdown Prettier만의 기능입니다.

## 주요 기능 상세

### 색상 헤딩 (Colored Headings)

각 헤딩 레벨에 고유한 색상을 부여했습니다.

- **H1** — Blue (`#61AFEF`) + 하단 보더
- **H2** — Green (`#98C379`) + 하단 보더
- **H3** — Yellow (`#E5C07B`)
- **H4** — Purple (`#C678DD`)
- **H5/H6** — Gray (`#ABB2BF`)

문서를 훑어보는 것만으로 구조를 파악할 수 있습니다.
특히 긴 기술 문서에서 "지금 어디를 읽고 있는지" 직관적으로 알 수 있습니다.

### TOC 사이드바

![Markdown Prettier 전체 화면 - 색상 헤딩, TOC 사이드바, 폰트 조절, PDF 내보내기](/images/posts/vscode-markdown-prettier/full-preview.png)

좌측에 자동 생성되는 목차 사이드바입니다.

- 클릭하면 해당 섹션으로 **smooth-scroll** 이동
- 현재 읽고 있는 섹션이 **자동 하이라이트**
- 접기/펼치기 토글 지원
- 동일 이름의 헤딩도 구분 가능

기존 확장들은 TOC를 본문 안에 삽입하는 방식입니다.
사이드바로 분리하면 본문을 읽으면서도 항상 전체 구조를 볼 수 있습니다.

![TOC 사이드바 - 현재 읽고 있는 섹션이 하이라이트됩니다](/images/posts/vscode-markdown-prettier/toc-sidebar.png)

### 프레젠테이션 모드

마크다운 문서를 바로 슬라이드로 전환합니다.

- `---` (수평선)을 슬라이드 구분자로 사용
- 상단 ▶ 버튼으로 진입
- `←` `→` 방향키로 이동
- `ESC`로 종료
- 슬라이드 카운터 표시 (예: `3 / 12`)

별도의 도구 없이 마크다운 문서를 그대로 발표에 사용할 수 있습니다.

### 폰트 크기 컨트롤

우측 상단의 `A-` / `A+` 버튼으로 폰트 크기를 조절합니다.

- 기본 12px, 범위 10~20px
- 설정이 세션 간 유지
- 화면 공유나 발표 시 유용

VS Code 전체 줌 없이 미리보기만 크기를 바꿀 수 있습니다.

---

### Mermaid 다이어그램

Mermaid 코드 블록을 작성하면 미리보기에서 바로 다이어그램으로 렌더링됩니다.

![Mermaid 다이어그램 렌더링 - 기술 스택 흐름도](/images/posts/vscode-markdown-prettier/mermaid-diagram.png)

Light/Dark 테마에 맞춰 다이어그램 스타일이 자동 전환됩니다.
별도의 다이어그램 확장을 설치할 필요가 없습니다.

### 라이브 편집

미리보기 화면에서 텍스트를 **더블 클릭**하면 바로 편집 모드로 진입합니다.

![라이브 편집 - 미리보기에서 바로 수정 가능](/images/posts/vscode-markdown-prettier/live-edit.png)

- 마크다운 파일을 왔다 갔다 할 필요가 없습니다
- `Ctrl+Enter`로 저장, `ESC`로 취소
- 수정하면 원본 `.md` 파일에 바로 반영됩니다

문서를 읽다가 오타나 수정사항을 발견하면, 그 자리에서 바로 고칠 수 있습니다.

## 기술 스택

- **markdown-it**: 마크다운 파싱
- **highlight.js**: 코드 신택스 하이라이팅 (Atom One Dark 테마)
- **mermaid.js**: 다이어그램 렌더링

VS Code의 Webview API를 사용하여 커스텀 HTML 미리보기를 구현했습니다.
기본 마크다운 미리보기를 교체하는 것이 아니라, 별도의 뷰어로 동작합니다.

## 설치 및 사용 방법

### 설치

VS Code 또는 Cursor의 확장 프로그램 탭에서 **"Markdown Prettier"**를 검색하면 바로 설치할 수 있습니다.

- **VS Code**: [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=lyhlg.markdown-prettier)
- **Cursor / 기타 에디터**: [Open VSX Registry](https://open-vsx.org/extension/lyhlg/markdown-prettier)

### 사용

설치 후 마크다운 파일을 열고:

- `Cmd + Shift + M` (macOS) / `Ctrl + Shift + M` (Windows/Linux)
- 또는 에디터 상단의 **MD 아이콘** 클릭

| 단축키 | 동작 |
|--------|------|
| `Cmd + Shift + M` | 미리보기 열기 |
| `▶` 버튼 | 프레젠테이션 모드 |
| `←` / `→` | 슬라이드 이동 |
| `ESC` | 프레젠테이션 종료 |
| `A-` / `A+` | 폰트 크기 조절 |

## 정리

1. ✅ **가독성 개선** — 헤딩 색상 구분으로 문서 구조를 한눈에 파악
2. ✅ **네비게이션** — TOC 사이드바로 긴 문서도 빠르게 탐색
3. ✅ **발표 지원** — 프레젠테이션 모드로 별도 도구 없이 발표
4. ✅ **세밀한 조절** — 폰트 크기, 테마 자동 전환, Frontmatter 숨김

개발자만 보는 문서가 아닙니다.
PO, PD, 기획자도 함께 읽는 문서입니다.

**읽기 좋은 문서가 좋은 협업의 시작**이라고 생각합니다.
